# Fix 502 Error - Daybreak Deployment

## Problem
Running `npm run migrate` during BUILD phase fails because DATABASE_URL isn't available yet.

## Solution Applied
✅ **Fixed in latest commit:** Migrations now run automatically when the server STARTS (not during build).

---

## What You Need to Do in Railway:

### Option 1: Update Build Command (Recommended)
1. Go to Railway backend service
2. Settings → Deploy
3. Change Build Command from:
   ```
   npm install && npm run migrate
   ```
   To just:
   ```
   npm install
   ```
4. Redeploy

The migration will run automatically when the server starts (after DATABASE_URL is available).

### Option 2: Just Redeploy
If your Railway is connected to GitHub and auto-deploys:
1. Just push this latest commit
2. Railway will auto-deploy with the fix

---

## How It Works Now

**Old (broken):**
- Build command runs `npm run migrate` → DATABASE_URL not available yet → ❌ FAIL

**New (working):**
- Build: just `npm install`
- Start: Server runs migrations first → DATABASE_URL available → ✅ SUCCESS → Then starts API
